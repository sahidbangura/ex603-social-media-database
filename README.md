# EX 603 Social Media Database

**Student:** Sahid Bangura  
**Course:** EX 603  
**Project Theme:** Social Media

## Project Overview

This project develops a relational PostgreSQL database for a social media platform.

The database will be designed to manage:

- Users
- Posts
- Likes
- Hashtags
- Relationships between posts and hashtags

The project will be developed across Units 1–6 and will include database design, SQL queries, analysis, documentation, and a final presentation.

## Technology

- PostgreSQL 18
- pgAdmin 4
- SQL
- GitHub
